# Power BI Case Studies

Four end-to-end analyses built with Excel, Power Query, Power BI and DAX on public Kaggle practice datasets. Each case study follows one pattern: **problem, approach, decision, financial impact**, with every assumption stated.

| # | Project | Data | Headline finding |
|---|---------|------|------------------|
| 1 | [Customer Churn & Retention](01-customer-churn) | 64,374 customer records | 47.37% churn; 71% churn beyond 15 days of payment delay vs about 10% before |
| 2 | [E-Commerce Revenue](02-ecommerce-revenue) | 50,000 orders, 2022-2023 | Discounts up to 30% sold no extra units per order (about 3.0); about $621K recoverable by re-pricing |
| 3 | [HR Attrition Risk](03-hr-attrition) | 1,470 employees | Overtime staff leave at 30.5% vs 10.4% (about 3x); 309 current employees rated High risk in the dataset |
| 4 | [Sales Profitability Rebuild](04-sales-profitability) | 9,223 order lines, 2014-2017 | Margin falls from 29% with no discount to -127% at 61%+ discount |

## Tools

Power BI (DAX measures, data modeling, interactive dashboards), Power Query (cleaning and shaping), Excel (formulas, PivotTables, modeling), statistical analysis (odds ratio, Cohen's d, correlation, logistic model).

## How to read the numbers

- All four datasets are public Kaggle datasets built for practice. Results demonstrate the method, not market findings.
- Dollar figures are **scenario estimates**, not realized results. Each project README states its assumptions.
- Each folder contains a dashboard screenshot. Power BI report files (`.pbix`) are added only where the dataset license allows redistribution; open them with Power BI Desktop (Windows).
